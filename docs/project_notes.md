# Cab Operations Analytics & Route Optimization System

## Objective

To analyze cab operations across major Indian cities and generate business insights using Python, SQL, Excel, and Power BI.

## Cities

- Hyderabad
- Bengaluru
- Mumbai
- Delhi
- Pune

## Cab Types

- Mini
- Sedan
- SUV
- Auto
- Bike

## KPIs

- Total Trips
- Total Revenue
- Average Fare
- Average Trip Distance
- Peak Booking Hours
- Top Drivers
- Most Popular Routes
- Driver Ratings

## Tech Stack

- Python
- SQL
- Excel
- Power BI
